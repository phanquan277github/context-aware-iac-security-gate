# Pilot Annotation Protocol

## Preferred

Two annotators independently rank findings within each scenario.

Annotators are blind to:
- model outputs
- baseline outputs
- predicted scores

## Fallback

If a second annotator is unavailable:

1. Perform Round 1 annotation.
2. Wait several days.
3. Perform Round 2 without consulting Round 1.
4. Measure agreement.
5. Report this as a self-retest limitation.

Self-retest must not be described as independent annotation.
